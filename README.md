# 🐑 Sheep Bloat Early Warning System (3D-EWS)

Sistem pemantauan otomatis berbasis **CCTV 3D** dan **Kecerdasan Buatan** untuk mendeteksi gejala dini *bloat* (kembung) pada domba secara non-invasif.

## 🌟 Fitur Utama
- **Real-time 3D Visualization**: Visualisasi point cloud abdomen kiri domba menggunakan Plotly.
- **Volume Quantification**: Estimasi perubahan volume fosa paralumbar secara otomatis.
- **Early Warning System (EWS)**: Notifikasi bertingkat (Safe, Warning, Critical) berdasarkan ambang batas distensi.
- **Historical Analytics**: Grafik tren volume untuk membedakan antara kenyang normal vs. kembung akut.
